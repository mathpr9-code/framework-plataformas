# 2. Fase 0 — Descoberta, escopo e risco

Antes de criar telas ou tabelas:

- [ ] Definir objetivo, usuários, papéis e processos de negócio.
- [ ] Identificar dados tratados: pessoais, financeiros, comerciais, credenciais e dados sensíveis.
- [ ] Identificar tenants/empresas e regras de isolamento.
- [ ] Listar integrações: Supabase, APIs externas, n8n, e-mail, pagamentos, IA, storage e webhooks.
- [ ] Identificar operações críticas: exclusão, exportação, pagamento, alteração de permissões, ações de IA e administração.
- [ ] Definir ambientes: desenvolvimento, homologação/staging e produção.
- [ ] Fazer modelo de ameaças: ativos, atores, entradas, fronteiras de confiança, dependências e impactos.
- [ ] Definir requisitos de disponibilidade, backup, retenção, auditoria e recuperação.
- [ ] Definir escopo de testes autorizados e dados fictícios para laboratório.

**Entregável:** Briefing técnico + mapa de dados + modelo de ameaças + requisitos não funcionais.
